# AI-ML-Internship
AI/ML internship at Next Gen Software Hub : Python, EDA, ML models  and a Titanic survival prediction app ( Gradio ).

Key Results

EDA: 74% of women survived vs 19% of men; 1st class 63% vs 3rd class 24%.

Week 3: Logistic Regression 83.8% test accuracy; cross-validation shows all three models at about 82.4%, so they are effectively tied.

• Week 4: Tuned Random Forest, 81% test accuracy (precision 0.79, recall 0.70, F1 0.74 for survivors). The model was chosen by cross-validation, not test score.
